What you're comparing
• Selection (both A & B fix it the same way): the entire row is clickable to select — radio dot, name, or empty space. The test control and ⋯ menu are small islands that do NOT change selection. The selected row is tinted + bold + has a blue bar, and shows an Active pill when connected.
• Test control — A vs B is the only real difference:
  — A (combined chip): compact. One thing. Tap it to test; it becomes the result. States: ⚡ Test ▲ 123 ms ⚠ Unreachable 🛡 Trust? PAC
  — B (button + chip): more explicit, wider. A Test button plus a result chip. Clearer that it's an action, uses more row width.
• “Trust?” (amber) only appears when the proxy is reachable but its TLS cert isn't trusted — clicking it opens the Trust-Certificate flow. A real unreachable shows Unreachable, not a cryptic “fail”.
• PAC-only proxies show a muted PAC (no latency to measure) instead of a red fail.
